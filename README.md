# UsefulTools

Small tools I build for my own daily work. Each one lives in its own folder with its own README.

| Tool | What it is |
| --- | --- |
| [ClaudeMonitor](ClaudeMonitor/) | A floating desktop orb showing Claude plan usage and live chat activity (macOS; Linux/Windows in testing) |
| [PaperLens](https://github.com/yufchen723/paperlens) | A Claude plugin for reading research papers end to end: paper folder, supplements, a summary shaped by the paper type, and a Paper Reader with Ask Claude and Translate (own repository) |
